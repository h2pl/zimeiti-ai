# 运营策划层（ops-plan）

> 五层流程第二层：**策划**。目标——把「一个热点」变成「一个带角度的可写选题」。
> 上一层：`ops-discover`；下一层：`ops-create`。

## 触发条件

用户要求判断赛道/选角度/定选题时先读本 SKILL。

## 执行步骤

1. **读画像**：`profiles/<画像>/identity.md`（定位/赛道）、`audience.md`（受众）、
   `style.md`（口吻约束）——没有画像信息时明说，不假设。
2. **契合度评估**：从流量潜力 / 账号匹配 / 竞争差异化 / 时效价值 / 变现潜力 /
   制作成本 / 合规风险等维度打分并给结论（适合 / 需变形 / 放弃）。
3. **二创角度**：给 2-3 个**真不同**的差异化角度（不是同题换标题）——每个一句话说明
   差异点与代价；标注最推荐的一个及理由。
4. **事实边界**：热点新闻只作引子，主体写技术原理/工程实践；不确定的数字不写。

## 产物约定

- 结构化结论：契合度结论 + 角度清单 + 推荐角度 + 推荐理由
- 如需用户拍板（两个角度难分高下），用 ask_human 给选项

## 交接条件

选题 + 推荐角度确定 → 进入 `ops-create`（制作层成稿）。
