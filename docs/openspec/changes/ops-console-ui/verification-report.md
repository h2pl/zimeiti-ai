# 验证报告：ops-console-ui（定时任务 + 用量控制台）

## Spec 场景逐条核对

| Requirement / Scenario | 结果 | 证据 |
|---|---|---|
| 查看任务列表（含空态/错误态） | ✅ | 浏览器实测①：进入自动化页；无任务时显示「还没有定时任务。点右上角新建任务…」 |
| 新建每日任务（后端错误回显） | ✅ | 实测②：填名称+默认 08:00 保存 → 列表出现「UI 探针任务」，显示「每天 08:00 · 下次 …」 |
| 立即执行与执行记录 | ✅ | 实测③：点「立即执行」→ 提示「已在后台开始执行」→ 记录区出现该次运行（状态/耗时/摘要） |
| 启停与删除 | ✅ | 实测④⑤：停用后卡片显示「已停用」并降透明度；删除后回到空态 |
| 用量在界面可查 | ✅ | 实测⑥：工作台出现用量卡片；设置面板 full 形态含区间切换与明细行；无数据显示「暂无用量数据」 |

## 自动化验证

- **tsc + vite build**：通过（先修 `IconEdit` 未用导入，构建再过）
- **浏览器实测**：六项全通（页可达 / 新建 / 执行记录 / 停用 / 删除 / 用量卡片）
- **`make check`**：全绿（exit 0）
- **全量 E2E**：52/54（S01 欢迎弹层两项首轮为已知偶发；单独复跑 S01 → 6/6 双端差异 0）

## 设计取舍记录

- **立即执行不同步等待**（D2）：后端本就是后台任务，UI 提示已提交并延迟 2s 拉记录，
  不假装同步完成（case 任务要跑几分钟）
- **用量不折算金额**（D3）：无单价数据源，界面明确标注「token（未折算费用）」，
  与契约「没有单价数据就不编造金额」一致
- **环境变量只读展示**（D4）：fallback 链 / 子代理模型改界面不会生效，
  故不做可编辑控件——展示假的编辑控件比不展示更糟

## 结论

定时自动化与用量首次在界面可见可管；后端能力全部产品化。**建议通过。**
