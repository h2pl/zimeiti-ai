## 核心工作流（品牌运营主线）

**热点 → 收藏为选题 → 一键排期 → 「做内容」带入对话创作 → 内容库归档 → 上传公众号草稿箱。**
选题与创作严格同源：对话指令由收藏的热点自动生成（产品原生「做内容」链路）。

其余典型路径（无独立视频，见 E2E 覆盖）：账号登录态自愈（S8）、设置面板模型通道（S9）、
全页面导航（S2）、首次引导弹层（S1）。

## 重新生成视频

```bash
# 品牌全流程
cd apps/api && uv run python ../scripts/record_brand_demo.py
# 五段路径 demo
cd apps/api && uv run python ../scripts/record_demo_suite.py
```

两个脚本都会：拉起真实后端（走 `.env` 真实 LLM）→ Playwright 驱动真实前端逐步操作
→ 录制转码 MP4 → **自动清理录制产生的演示数据**（会话/排期/选题/画像）。
