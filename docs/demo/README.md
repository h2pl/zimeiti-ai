## 视频中的用户步骤（选题 → 创作全程围绕同一条热点）

| 步骤 | 页面 | 操作 |
|---|---|---|
| ① | 工作台 | 选题、排期、内容、账号四项概览一屏总览 |
| ② | 热点雷达 | 浏览微博/抖音/知乎实时热点（后台自动保热，秒开） |
| ③ | 热点雷达 | 点「收藏到选题库」——热点一键转选题 |
| ④ | 选题库 | 对**刚收藏的这条**选题点「排期」一键排入日历 |
| ⑤ | 内容日历 | 排期条目、发布节奏与断更缺口一目了然 |
| ⑥ | 对话 | 回到热点点「**做内容**」——选题自动带入新会话，AI 判断赛道契合度 → 给差异化二创角度 → 流式写出推荐角度的**文案初稿** |
| ⑦ | 内容库 | 成稿归档，在线预览全文 |
| ⑧ | 账号中心 | 公众号已配置——文章一键上传草稿箱（**只建草稿，绝不自动发布**） |

## 一句话总结工作流

**热点 → 收藏为选题 → 一键排期 → 「做内容」带入对话创作 → 内容库归档 → 上传公众号草稿箱。**
选题与创作严格同源：第 ⑥ 步对话的指令由第 ③ 步收藏的热点自动生成。

## 重新生成这个视频

```bash
cd apps/api && uv run python ../scripts/record_brand_demo.py
```

脚本会：拉起真实后端（走 `.env` 真实 LLM）→ Playwright 驱动真实前端逐步操作
（带步骤横幅与拟人鼠标）→ 录制转码为 MP4 → 自动清理录制产生的演示数据
（会话/排期/选题）。
